# Interval Timer

40秒動いて、20秒休む。それをくり返すだけのシンプルなインターバルタイマーです。
アプリのインストールやログインは不要で、ブラウザで開けばそのまま使えます。

**使ってみる:** https://pokkomyu.github.io/interval-timer/interval-timer.html

## 特徴

- 動く40秒と休む20秒を自動で切り替え
- 動く時間は画面がピンク、休憩はグリーンに変わる
- 切り替わる3秒前から音で知らせ、切り替わりは音とバイブで知らせる
- 秒数とラウンド数は＋/−で変更できる（初期値は40秒・20秒・8ラウンド）
- 一時停止とリセットに対応
- 動作中は画面が消えにくい

## 使い方

1. 上のリンクを開く
2. 必要なら秒数とラウンド数を変える
3. 「スタート」を押す

スマホがマナーモードだと音が鳴らないので、そのときはバイブと画面の色で確認してください。

## ホーム画面に追加する

- **iPhone（Safari）:** 共有ボタン →「ホーム画面に追加」
- **Android（Chrome）:** 右上の「︙」→「ホーム画面に追加」

## 技術

HTML・CSS・JavaScriptだけで作った、1ファイル（`interval-timer.html`）のページです。外部のライブラリは使っていません。
